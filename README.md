## Project Structure

```
frontend/          React + TypeScript frontend (Vite)
backend/           FastAPI Python backend
agent/             BESSER Agentic Framework conversational agent
render.yaml        Render Blueprint deployment config
docker-compose.yml Local development setup
```

## Deploy

Click **Deploy to Render** above to deploy the **`feat/baf_sql_agent`** branch of [`prasadadhav/leaderboard`](https://github.com/prasadadhav/leaderboard), using the root `render.yaml` Blueprint.

The Blueprint configures three services: the frontend, the backend API, and the BAF WebSocket agent. Check the generated service URLs and build-time `VITE_API_URL` / `VITE_AGENT_URL` values before publishing. Deployments follow new commits on this branch when auto-deploy is enabled. The agent may need more memory than Render's free instance provides.

> The button follows the branch's latest commit; it does not pin one SHA. To inspect the exact version, check the [branch commit history](https://github.com/prasadadhav/leaderboard/commits/feat/baf_sql_agent) or Render deployment logs.

## Local Development

**Frontend:**
```bash
cd frontend && npm install && npm start
```

**Backend:**
```bash
cd backend && pip install -r requirements.txt && uvicorn main_api:app --reload
```

**Full stack (Docker):**
```bash
docker compose up --build
```
